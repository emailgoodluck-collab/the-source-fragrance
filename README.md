# The Source Storefront

Standalone one-page luxury fragrance storefront for private catalog browsing,
availability requests, and fragrance consultation.

## Configure before launch

1. Set the real Namecheap mailbox in `script.js`:
   `inquiryEmail: 'bookings@your-domain.com'`.
2. Replace the illustrative fragrance cards with actual stock records, bottle
   sizes, verified retail prices, and supplier-provided authenticity details.
3. Add the business name, address, delivery rules, returns policy, WhatsApp,
   and social links once supplied by the owner.

No payment collection is implemented. The inquiry flow opens the configured
business mailbox so availability and final price are confirmed first.
